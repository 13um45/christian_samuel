Flash utility

Update your pedal's firmware from the browser.

This browser can't flash.

Flashing uses WebUSB, which only Chromium-based desktop browsers support — Chrome, Edge, Opera or Arc on macOS, Windows or Linux. Firefox, Safari and every browser on iOS or Android will not work. Open this page in one of those instead.

  1. Plug the pedal into this computer with USB.
  2. Press Open connection window below. A browser window opens listing USB devices. It will be empty — that is expected.
  3. With that window still open, press RESET on the pedal. It appears in the list a moment later.
  4. Select it and press Connect. Flashing starts immediately.

The window must be open before you reset the pedal. Reset it first and it leaves update mode after about two seconds — long gone by the time the window appears.

The window is open. Now reset the pedal.
  1. Press RESET on the pedal.
  2. It appears in the list within a second or two.
  3. Select it and press Connect. Flashing starts immediately.

An empty list just means the pedal isn't in update mode yet. Reset it again — the list updates live, so there's no rush.
